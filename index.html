The Strategy

This is not ordinary sorting. We use a bespoke comparator that treats every pair as a binary trade: which concatenation yields the higher payout?

Comparator Alpha

For any two strings a and b, compare (b+a) against (a+b). If b+a is larger, b belongs first. This local decision produces the globally maximal concatenation.

Proof of Optimality

The comparator is transitive on digit strings, so a total order exists. By the rearrangement inequality and induction, greedy local placement yields the global maximum.

Complexity

O(n log n · k) where k is average digit length. The comparison itself is O(k) string concat and lexicographic scan. Memory is O(n·k).

Edge Handling

Zero-heavy inputs collapse to zero. The parser rejects negatives and non-integers. Output returns as a number to satisfy the original contract.

function maxCombine(xs) {
  if (!Array.isArray(xs) || xs.length === 0) return 0;
  const nums = xs.filter(x => Number.isInteger(x) && x >= 0);
  if (nums.length === 0) return 0;
  const sorted = nums.map(String).sort((a, b) => (b + a).localeCompare(a + b));
  const joined = sorted.join('');
  return joined[0] === '0' ? 0 : Number(joined);
}
from functools import cmp_to_key
from typing import List

def max_combine(xs: List[int]) -> int:
    if not xs:
        return 0
    nums = [x for x in xs if isinstance(x, int) and x >= 0]
    if not nums:
        return 0
    def comparator(a: str, b: str) -> int:
        if a + b > b + a:
            return -1
        if a + b < b + a:
            return 1
        return 0
    joined = ''.join(sorted(map(str, nums), key=cmp_to_key(comparator)))
    return 0 if joined[0] == '0' else int(joined)

import java.util.*;

public class MaxCombine {
    public static long maxCombine(int[] xs) {
        if (xs == null || xs.length == 0) return 0L;
        List<String> nums = new ArrayList<>();
        for (int x : xs) {
            if (x >= 0) nums.add(String.valueOf(x));
        }
        if (nums.isEmpty()) return 0L;
        nums.sort((a, b) -> (b + a).compareTo(a + b));
        String joined = String.join("", nums);
        return joined.charAt(0) == '0' ? 0L : Long.parseLong(joined);
    }
}
